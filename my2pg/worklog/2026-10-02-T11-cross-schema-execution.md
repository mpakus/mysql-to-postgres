# 2026-10-02 — T11 cross-schema execution

Status: implementation slice in progress; this is not T11 acceptance. Ownership: `src/pipeline/mod.rs`, the new native runner case, its integration registration, and this worklog. Do not change another worker's T15 enum-verification files.

## Contract and boundary

Table rename mappings may choose PostgreSQL destination schemas. A run must inspect and plan every selected destination namespace, then hold the existing per-schema migration advisory lock for each planned namespace before a source snapshot, reinspection, DDL, or row writes. Acquire locks in deterministic sorted order so overlapping runs cannot deadlock. A lock conflict must fail before writes and release any locks this run acquired. Unselected schemas are not part of the lock set. Locks coordinate my2pg runs only; they do not serialize unrelated DDL clients. This slice does not close the broader T11 identity, reset, or existing-policy matrix.
