Production run now computes A before target mutation, reserves it in Resources, and uses the exact current executable private worker. Child receipts cover create, plan, initial report and all later report/reject operations. After sources/targets close, finalization awaits the outstanding actor prefix for at most3 seconds, reconciles confirmed per-table reject counts before fault row accounting, and attempts final report publication for at most3 seconds. A failed newer report produces a fixed artifact diagnostic naming last confirmed generation and a fallible console outcome; returned I/O error also names that generation. These application deadlines do not guarantee kernel-uninterruptible process exit or persistence of an unacknowledged suffix.
