## Chosen adaptation and acceptance

Implement the smallest independent primitive that can be safely integrated once canonicalization is frozen: compare two iterators of already-canonical row byte strings by exact lexicographic external sort. It uses bounded in-memory sort runs, bounded two-way merge passes and length-prefixed records, preserving duplicates and avoiding digest-collision assumptions. A too-small budget, oversized single row, temporary-storage error, or unsupported filesystem must be an explicit error; callers must report content coverage as incomplete/unsupported, never Complete. Tests cover equal-count value corruption, order independence, duplicate multiplicity, empty streams, and multi-run merging.

This slice intentionally does not claim T18 complete. It does not yet produce canonical typed bytes from MySQL/PG values, enforce the same source snapshot as the migration, handle append baselines, or connect into final report persistence. T11/T13/T15 dependencies and their open gates remain blockers to end-to-end T18.

## Bounded-run review correction

Coordinator review found the first implementation retained a `Vec<PathBuf>` for every run, so its path metadata grew with input size. Replaced that collection with online binary-carry run levels: each level holds at most one path, every merge opens two inputs, and retained path metadata is `O(log(run_count))`. Each input row is rejected if either its length or retained Vec capacity exceeds `memory_bytes / 8`; accepted chunk accounting charges capacity plus the Vec header. This avoids retaining oversized spare allocations and avoids a shrink operation's transient old-plus-new allocation. Record readers reject framed lengths above the same bound before allocating payload storage. A successful comparison must explicitly remove its private scratch directory; cleanup failure returns `Storage`, while Drop remains best-effort for earlier failures. Scratch directory/file permissions are 0700/0600.

After the correction, `bin/cargo check --offline --locked --lib` passed, restoring shared Cargo compile consistency before the coordinator resumed its T11 lane. Focused `bin/cargo test --offline --locked --lib verify::content::tests -- --nocapture` passes 6/6, including 256-run logarithmic bookkeeping, rejection of a one-byte row with oversized Vec capacity, and a `u64::MAX` framed-length refusal before allocation. Strict all-target/all-feature Clippy, formatting check, and `git diff --check` pass. No integration registration, shared index or database lane was changed/run here.

Coordinator registered the pure integration cases in `tests/integration.rs`; `bin/cargo test --offline --locked --all-features --test integration t18_content:: -- --nocapture` passed **2/2**, followed by `bin/cargo fmt --all -- --check` and `git diff --check`.
