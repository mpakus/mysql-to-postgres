Existing Rust config/importer/CLI tests remain the behavioral checks for rejection before target access. The test must require the MySQL and PostgreSQL transport crates, reject known alternate database-driver packages and non-MySQL source markers, run on the host platform, clean up its temporary install, and avoid misclassifying PostgreSQL target support as PostgreSQL source support.
