## Contract mapping and proof

- Catalog operation classes: `source_mysql_catalog` and `target_postgresql_schema_table_prepare`. Start before the first catalogs read; end after all `DdlPhase::Prepare` DDL completes. The interval deliberately includes intervening planning/consistency checks and target preparation setup; document this inclusively and never call it a disjoint sum component.
- COPY operation class: `row_copy`. Aggregate the earliest start and latest completion across the existing table/range pipeline boundaries; keep those table-scoped diagnostic values separate. Copy/index intervals are independently recorded and may overlap.
- Index/constraint operation classes: `primary_keys`, `indexes`, `foreign_keys`, `check_constraints`. Start before finalization work; end after finalization DDL, before sequence resets.
- Verification is not emitted by this producer: the benchmark runner's independent source/target correctness oracle owns that phase for both loaders. Do not treat My2pg's optional in-run verification or the runner's pre-seed source digest as a substitute.

Add a console serialization unit test for the exact JSON event and phase-boundary tests that assert one run clock, earliest/latest COPY across concurrent table/range windows, overlapping COPY/index intervals, and catalog/index end points.
