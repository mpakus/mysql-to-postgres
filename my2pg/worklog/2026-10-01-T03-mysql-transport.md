## Ownership guard research (before change)

The fresh harness proved the initial cancellation assertion could misleadingly pass by draining the 780MiB result in 3 seconds. Another fresh run timed out at 5 seconds. XERJ `ref-mysql_async` symbol `clean_dirty` returned `src/queryable/mod.rs:102`, which drops/drains pending results; read `src/conn/mod.rs:900–924` and **actual downloaded mysql_async 0.37.1** `src/conn/mod.rs:451–459,974–980`, `src/conn/pool/mod.rs:363–391`. Even explicit disconnect calls `clean_dirty`. However, it sets the disconnected flag before the first await, so polling its owning future once then dropping it closes the owned socket and prevents the unbounded drop-cleanup task.

Coordinator approved a concrete `SourceConnection` guard; its Drop and explicit cancellation both use that tested ownership behavior. No pool or generic source interface is added. Acceptance uses a deliberately slow 100,000-row result (`SLEEP(0.01)` per row, roughly 1000 seconds if accidentally drained), asserts cancellation returns within one second, and polls the real server for connection disappearance. Dependency upgrades must rerun these cancellation and automatic-drop regressions.

The projection contract is explicit: original qualified identifiers are retained; textual/ENUM values are cast to binary to preserve original charset bytes; SET values are projected as unsigned masks in catalog label order. A 64-label real SET test asserts the first and highest bits. Oracle MySQL itself rejects comma-containing SET labels; the fixture proves that rejection rather than pretending such a source table can exist. Generated target columns are omitted from COPY. Catalog additionally captures inspected session increment/offset, which does not certify every source writer's own session generator settings.

- `connect(&SourceConfig, resolved_url, max_row_bytes)` returns a non-cloneable `SourceConnection` guard. TLS defaults verify CA/hostname; optional PEM client identity is supported. URL transport overrides/parameters are rejected. Every reader gets UTC; only supported session settings are accepted. The packet bound is raw row limit plus 64 KiB, subject to the driver's 1 KiB–1 GiB bounds.
- `inspect(&mut Conn)` returns exact original table/column/type/default/comment/generated/invisible metadata, ordered per-part indexes and FK endpoints/actions, enforced CHECK metadata on capable versions, view identities, unsupported routines/events/triggers/partitions/storage/invisible-index inventory, estimated rows, next identity and effective identity increment/offset. All query failures propagate; known version capabilities select appropriate metadata fields. Oracle variants and untested version lines fail explicitly. Inventory is subject to source-account metadata visibility; it does not certify hidden objects or other users' grants/session settings.
- `enforce_consistency` validates the caller's **selected** catalog for InnoDB when using a single snapshot; the coordinator must filter excluded tables before calling it. `start_snapshot` starts one repeatable-read read-only consistent transaction. Real tests reject an INSERT and retain a pre-update value across repeated reads, then see the new value after rollback.
- `table_stream` returns prepared-protocol raw rows with original qualified names and the projections above. `raw_values` preserves all raw variants and explicitly rejects an oversized workspace. `cancel(SourceConnection)` consumes the source ownership guard; Drop also closes an abandoned reader without draining its remaining result.
