## Native proof design

- Control verification: full migration with a gated final FK DDL, then lock an independent selected target table after all COPY ACKs and before releasing the FK gate. Observe actual target COUNT(*) blocked during verification, cancel, require exit130/no induced VERIFICATION_EXECUTION, all ACKs retained, no unknown rows, closed owned sockets.
- Concurrent index cancellation: actual schema-only I2 index jobs blocked on an owned event-trigger advisory gate; cancel both before COMMIT, require exit130/no false failed DDL ledger entries/no unknown rows, all index/control sockets disappear within deadline.
- Scoped production runner panic: real ACK prefix on one table; sibling real blocked COPY/full queue. Trigger the approved scoped Rust panic at that worker's progress event. Require fatal WORKER_PANIC, original ACK/report/bytes retained, sibling rollback/no replay, source/target guards closed and permits recoverable. No fake SQLSTATE, storage errno or public production fault switch.
- Pure bounded collector oracle: a first error published before stop remains authoritative if teardown/deadline produces only synthetic Cancelled; later Indeterminate still wins; equal-ranked later errors cannot replace the initial code/message. Locks are synchronous/short.
